# Master_thesis

The codebase and thesis present new methods for processing 1D and 2D NMR data, offering several advantages over the current state of the art. Following my completion of this work at DTU, research groups at both DTU and KU have continued development based on my initial findings. Because these ideas and implementations form a central part of ongoing patent applications and scientific publications, the code and thesis cannot be made publicly available until 2027.
